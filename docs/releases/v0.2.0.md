# nodectl v0.2.0

本版本增加签名安装、自升级、doctor/status、配置向导、首次安装基线和安全卸载；保留现有配置事务模型。完整变更见 CHANGELOG.md。

## 安装与验证

下载对应 Linux 架构归档、SHA256SUMS、SHA256SUMS.sigstore.json 以及 install.sh。按 installation.md 校验签名身份和摘要；不需要在目标 VPS 安装 Rust。归档含 SBOM、依赖许可证和构建信息，GitHub 构建证明可追溯提交与工作流。

## 兼容、迁移与回退

支持 schema/template v1；0.1 快照只有完全重新生成一致才接受。工具升级不改凭据、不升级 Xray/Nginx/usque/acme.sh，也不重启服务。旧程序按摘要保留；配置事务失败使用 recover，再判断 rollback。未知 schema 拒绝。

0.1 历史安装没有完整首次服务基线，无法自动安全卸载，须按原部署记录恢复；新安装默认保留证书、WARP 和用户数据。Xray 锁定版本为预发布；上线前必须完整协议验证。

系统与架构结果以本标签的成功工作流和资产为准。未完成签名、构建证明或集成验收时不得将候选草稿公开为正式版本。

系统验收沿用 [源码集成证据](https://github.com/i0721/dmit-node-config/actions/runs/38969822266)：四个 x86_64 系统，以及 ARM64 Debian 12、Ubuntu 24.04 的任务通过。ARM64 Debian 13 的运行日志通过但任务收尾被取消；Ubuntu 26.04 ARM64 未完成。用户要求停止等待扩展 ARM64 矩阵，故工作流总体显示取消，不代表已成功任务失败，也不代表全部 ARM64 系统已支持。发布阶段不重复系统矩阵，仍强制两个架构的原生测试、归档自检和签名安装验证。
