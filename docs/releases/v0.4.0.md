# nodectl v0.4.0

状态：源码实施与本地隔离验收完成，尚未发布。仅推送标签不会证明生产已部署。

- 新增受 Token 保护的节点页面和 Mihomo / Xray 分发端点，复用当前成功快照及现有客户端生成器。
- 新增 `share status/reveal/rotate/revoke`，支持随机及自定义初始凭据；普通日志不输出 Token 真值。
- Nginx 提供 HTTPS、限流、禁用缓存与专用日志保护，同一 Rust 程序经私有 Unix socket 处理鉴权，不增加公网端口或管理面板。
- 分发服务纳入部署备份、升级、回滚和卸载。Token 撤销独立于节点快照，旧版回滚不恢复已撤销凭据。
- 模板 3 独立版本化，模板 1、模板 2 的已知版本和完整性验证继续保留。

访问教程见 [安全节点分发](../node-access.md)，实施和验收标准见 [计划](../defect/09-secure-distribution-plan.md)，实际验证及限制见 [验收记录](../defect/10-secure-distribution-results.md)。已下载的节点凭据不因订阅 Token 撤销而自动失效。
