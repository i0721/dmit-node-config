# nodectl v0.5.1

本补丁修复早期已管理部署缺少 `installation.json` 时的 CN 策略恢复。0.5.0 的功能与渲染格式保持不变，旧标签和资产不覆盖。

- 完整回滚恢复旧配置与服务后，根据外层恢复日志判断 CN 策略是否由本次部署新增。仅释放该策略自己的规则与拒绝路由，再执行原有严格路由一致性检查；原先存在的策略继续保留，所有权漂移继续拒绝。
- 恢复未启用但已链接的 systemd 单元时，保留恢复记录对应的入口，避免 `systemctl disable` 连同入口一起删除而无法回到原状态。
- 新部署日志明确备份 CN 数据链接、网站公开入口及新增 systemd 单元，完成回滚后可再次部署；旧日志仍按其原有精确文件清单和摘要验证，不把缺项视作通过。
- 兼容 0.5.0 与 0.5.1 的模板 4 快照，继续完整校验文件清单和摘要。已用正式签名 0.5.0 程序生成 CN/网站快照，并由 0.5.1 验证；不轮换客户端身份、证书或凭据。
- 新增隔离内核策略测试和真实 0.4 服务缺少安装基线时的部署、完成回滚及失败恢复场景。实际结果与生产状态记录在 [验收报告](../defect/12-cn-warp-web-services-acceptance.md)。

生产执行仍须审阅具体资产与变更预览。发行或本地验收通过，不表示网站已经在生产上线。
