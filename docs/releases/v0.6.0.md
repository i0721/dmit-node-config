# nodectl v0.6.0 — DMIT 单机 Web 管理后台

发行包由 GitHub 发布工作流构建，完成 SHA256 清单签名和来源证明验证后公开。安装时必须验证官方签名。

新增静态 DMIT Console 与 Rust 单管理员 API，覆盖总览、节点订阅、配置、网络/WARP、DNS/双证书、服务和运维七页。复用 console-web 的基础包和插件架构；生产不运行 Node.js。

默认配置保护由 Rust 强制执行。环境资产可编辑，平台字段须重新认证、审阅差异、真实检查及输入计划标识确认；不可绕过 TLS1.3/H2/H3、路由和执行路径等边界。现有配置、原节点 Nginx 和历史发布优先保留，变更复用现有事务与恢复机制。

发行归档包含静态文件、版本摘要清单和前端许可证声明。签名验证通过后，可通过 `install.sh --with-admin` 安装独立 HTTPS 9443 入口；已有节点也可通过 `nodectl admin install --archive /absolute/release.tar.gz --execute` 安装。手动本地归档须先验证官方签名。首次显示管理员 Token，后续安装保留；`nodectl admin reset-token` 可重置并撤销全部会话。

保留原 CLI 和自动部署默认行为。后台升级 CLI 后通过受控 API 重启使用新版；静态 UI 更新使用同版本发行归档再次执行 admin install。UI/API 归档版本不匹配会被拒绝。详见 [安装与管理](../web-admin-design.md)。
