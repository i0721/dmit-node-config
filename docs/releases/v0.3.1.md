# nodectl v0.3.1

统一 Linux 原生一键安装、交互部署和保留配置升级入口。下载并执行根目录 install.sh 后自动安装已验签的 nodectl，进入 Rust 向导，完成配置收集、变更预览、终端确认、部署验证和客户端导出。目标主机不需要 Rust 或容器运行时。

- 新增 `nodectl deploy --wizard`，不重复收集输入或要求手工复制计划摘要；无终端时拒绝隐式执行。
- 自动准备固定摘要的官方 cosign，验证 Release 签名、工作流身份、架构和版本；安装失败保留原程序，恢复未完成时拒绝降级。
- 支持 Cloudflare Zone 自动识别、安全凭据输入及私密保存，保留手动配置和显式非交互审批方式。
- 纳入 0.3 的双域名、中性公开页面、独立 VLESS Encryption/Vision 参数及同源 Xray/Mihomo 客户端导出，修正 UDP/QUIC 设置。
- 严格兼容 0.1/0.2 模板 1 及 0.3.0/0.3.1 模板 2 快照，不放宽原始完整性校验。
- 全量质量与系统集成工作流改为手动运行；发行使用专用构建环境，仅打包、检查归档、生成 SBOM、签名和验证来源证明，避免重复本地测试。

新配置默认主名称 speedtest、REALITY 名称 files。旧配置不会自动改名、开启 Encryption 或轮换密钥；显式更改兼容字段时必须更新客户端。WARP 继续保持独立路由，不接管默认出口。

服务、证书、DNS 的变更仍需审阅具体计划。自然续期周期、真实公网故障恢复等验收边界以实际测试报告为准；安装成功不能替代完整部署成功。
