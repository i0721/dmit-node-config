# nodectl v0.5.0

本版本增加可选独立 CN WARP 与原生网站服务，继续使用同一条安装命令和 Rust 配置、审批及事务模型。发行不表示生产主机已升级。

- CN 域名或 IP 经独立 usque 实例、凭据、TUN 和策略表；其余流量原生直连。分流 DNS、双地址族拒绝守卫和接口停止处理共同防止隧道故障时直连回退，不更改系统默认路由。
- 主域名提供中性 Landing Page、官方 LibreSpeed Go 测速及测试下载；files 域名运行原生 OpenList，保留 REALITY SNI、传输路径、TLS/H2/H3、IP 证书与安全订阅。
- 两个网站后端仅监听 loopback，使用独立非登录用户。既有身份、密钥、管理员、文件和存储配置优先保留；首次密码通过受保护终端取回。
- GeoIP/GeoSite、两架构原生程序及归档摘要锁定。模板 4 独立版本化，继续严格验证已知旧版快照；私密快照不公开，Xray 只读取两份经摘要校验的公开数据副本。
- 网站数据库在维护状态下备份，新增程序、服务和材料纳入恢复；完成回滚拒绝覆盖已漂移数据库，卸载保留数据库与上传文件。

本地证据包括真实双 WARP、完整 systemd 部署/故障恢复/停止/强杀重启/卸载、历史 0.4 升级回滚、两内核三传输 TCP/UDP/强制 QUIC、实际测速和 64 MiB 文件权限测试。未重跑完整四 amd64 系统及 ARM64 运行矩阵；不以构建成功代替运行验收。生产连通性、生产续期及公网大流量测试未验证。

使用见 [CN WARP 与网站服务](../cn-warp-web-services.md)，证据及限制见 [阶段验收报告](../defect/12-cn-warp-web-services-acceptance.md)。旧配置缺省不启用新功能，需要在部署向导中明确选择。
