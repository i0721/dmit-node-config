# 安全边界

项目不能防御已控制 root 的攻击者。威胁模型覆盖配置篡改、误覆盖、凭据进入日志、不可信程序、应用中断和恢复错误。

快照权限 owner-only，摘要后重新生成比对；收据固定程序、证书与 WARP 摘要；root 独占锁；Xray 使用 systemd LoadCredential。工具不关闭 TLS 验证、不接管默认路由，不在 render/apply 注册外部账户。

安装器信任受控版本标签工作流和 GitHub OIDC，通过官方 cosign 校验签名及透明日志。cosign 本身属于信任根，须从官方可信来源安装。摘要只校验完整性，单独的同站摘要不能证明来源。

输入、客户端导出、WARP、acme.sh 与备份均可能含凭据，目录 0700、文件 0600，传出前加密。公开文档只用 example.com 与文档地址。Xray 固定预发布版本仍须隔离验收，旧程序和备份须保留。

漏洞报告见 [SECURITY](../SECURITY.md)。卸载不能弥补缺失的历史记录；旧版无基线时拒绝自动卸载是安全要求。
