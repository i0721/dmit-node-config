    如何导入

    Mihomo：将节点订阅地址用于 proxy-providers 的 HTTP provider，再在自己的代理组引用该 provider；保留原有规则。

    Xray：下载的 profiles.json 是命名 outbound 集合，选择所需 profile 的 outbound 合并到自己的配置。它不是所有客户端通用的订阅协议。

    客户端需支持服务器使用的 VLESS Encryption、Vision 和 XHTTP。下载文件含客户端凭据，请安全保存。
