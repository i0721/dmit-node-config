# DMIT 后台需求

单台 DMIT VPS；一个管理员 Token；无注册、多用户、角色、数据库、终端或通用文件管理。

页面必须使用真实 Rust API。总览使用 Linux 实测数据；节点只导出成功发布；配置默认只编辑环境资产；网络观察原生出口与双 usque/CN 策略；DNS/双证书管理保留既有依赖与 ACME；服务固定允许列表；运维复用部署、升级、健康检查、备份、回滚、恢复和审计。

核心验收是：默认 DMIT 参数和身份不变；前端无权绕过后端；高级变更有原值、diff、二次确认及恢复；CLI/自动部署继续兼容。必须执行真实 HTTPS/API 联调、浏览器视觉、安全权限、升级回滚和全回归，不用前端 fixture 代替后端验收。
