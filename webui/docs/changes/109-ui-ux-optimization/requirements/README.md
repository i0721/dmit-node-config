# 要求

核心导航与操作可见可达；切换保持当前身份与输入；本地演示结果可信；
组件/页面/Host 使用同一设计系统；尺寸、locale、density 变化没有裁切或整页溢出。
保留八设置路由、Next 唯一路由、已有偏好/草稿 key 与旧数据兼容。
