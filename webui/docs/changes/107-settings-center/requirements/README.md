# 107 需求摘要与导航

面向客户与产品使用方（设置中心的用户与"使用设置的页面/Shell"两类消费者）的可验收行为。
不混入内部类名/包路径/调用链；需求只描述能力、限制与风险。

- [八分类设置页与即时生效](settings-page.md)：外观/导航/数据展示/操作偏好/语言与地区/
  通知/可访问性/快捷键的设置项、搜索定位、恢复默认与状态表达。
- [导航、页面标签与工作恢复](navigation-tabs-workspace.md)：启动目标、离开确认、页面标签、
  收藏/最近、工作状态恢复。
- [列表、表单与操作行为](list-form-actions.md)：列记忆、草稿、提交去向、确认与刷新、
  搜索历史、地区格式。
- [通知、命令与快捷键](notifications-shortcuts.md)：通知中心、桌面通知、提示音、命令与
  快捷键。

## 范围与边界（总）

- 设置在**当前浏览器**持久化；不接账号/后端/跨设备同步。自动保存指本地草稿；通知来源为
  真实前端事件与真实本地任务结果，不预填虚构。
- 所有用户可见文本、日期、时间、数字与相对时间统一走 i18n，不在页面硬编码。
- 只做产品允许的能力偏好：新页面打开方式只作用于声明允许的入口；危险操作既有输入确认
  不能被全局偏好削弱；高风险/错误/安全提示不能完全关闭。
- 不提供"设置页设计器"能力（无自定义圆角/阴影/间距/任意 CSS/任意 px/Design Token 编辑），
  快捷键不做任意键位编辑器。
- 分类恢复与全部恢复只恢复偏好，不触碰账号/业务数据、收藏、历史、通知、草稿与已保存筛选
  方案；均有二次确认并列出影响范围。
