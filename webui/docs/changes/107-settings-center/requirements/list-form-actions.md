# 列表、表单与操作行为

## 客户目标

作为高频录入用户，我希望列表与表单记住我允许保存的状态（每页条数、列布局、筛选、滚动、
草稿），让"返回列表/继续上次"不丢失上下文；提交、删除、重置、离开与刷新等动作按我的偏好
确认或自动执行，但产品的高风险底线不被削弱；搜索行为与历史、地区数字与日期格式都贴合我的
习惯。

## 使用场景与可验收行为

### 列表状态与列

- 设置中心管理**全局默认**（每页 10/20/50/100、表格密度、分隔、固定表头、列布局/排序/
  筛选/分页记忆开与关、空态说明、长文本截断/换行）；具体列表通过稳定页面/列 ID 保存覆盖
  值。生效优先级固定为：业务强制约束 > 当前显式操作或 URL > 已保存页面覆盖 > 全局默认。
- 列宽调整直接操作（HeroUI Resizable）；列顺序用可键盘操作的前移/后移按钮；列显示/隐藏
  可切换。恢复列布局时过滤已退役列并保留必要标识列。
- 分页在筛选、删除或页大小变化后自动校正到有效页；不恢复危险的批量选择状态（批量选择是
  瞬时操作）。
- 返回列表恢复已允许保存的筛选、分页与滚动；显式 URL 条件优先。

### 草稿与自动保存

- 自动保存只写页面**显式允许**的本地草稿字段；不等于业务提交成功；有未保存内容时显示
  未保存状态。
- 恢复草稿后仍是"未提交"语义（继续编辑/提交走正常流程）；业务提交成功后清草稿；**提交
  失败不清草稿**；草稿冲突（多窗口/刷新时序）不得静默覆盖（保留恢复/覆盖的明确选择）。
- 离开有未保存内容时提醒（应用内确认 + 必要的浏览器原生提醒）。

### 提交、重置、删除与刷新

- 编辑成功后去向：留在当前页 / 返回列表 / 进入详情（只在**真实成功回调后**执行；缺少详情
  目标的页面明确说明该选项不适用）。
- 创建成功后去向：返回列表 / 继续创建 / 打开新建详情（真实成功回调后执行）。
- 重置前确认（表单有改动时）；删除、批量、清空等高风险操作确认；危险操作**既有输入确认**
  （如输入名称才能删）不被全局偏好削弱。
- 自动刷新数据：关闭 / 仅页面重新进入时 / 定期刷新（统一产品预设周期；后台、离线、提交中
  暂停；不并发重入；不覆盖未提交编辑）。不向用户暴露毫秒参数。

### 表单聚焦与反馈

- 自动聚焦第一个可编辑字段（默认关）；校验错误后自动定位到首个错误字段（默认开，表单
  校验基础设施已具备该语义）。
- 复制内容后显示反馈（开/关）。
- 详情附加信息自动展开（开/关）；默认详情展示模式（简洁/完整——仅当项目已有该模式）。

### 搜索行为与历史

- 搜索时机：输入后自动搜索 / Enter 后搜索（不暴露 debounce 毫秒）。
- 是否保留各页面最近一次搜索条件；是否保留最近搜索（记录）；是否显示搜索历史；是否显示
  搜索建议（默认开）；清空搜索历史的独立明确操作（关闭"记录/显示"不连带删除已存历史）。

### 语言与地区（列表/表单侧）

- 日期、时间、数字、相对时间与单位统一经 i18n 格式化；纯日期不因时区发生日期偏移。
- 界面语言切换后：日期选择器界面语言与一周起始日（周一/周日）跟随；数字千位分隔跟随
  地区；时区自动或指定 IANA 时区（影响时间显示，不影响纯日期）。
- 相对时间偏好：近似"5 分钟前"或精确时间。

## 参考场景（验证"真实使用链路"而非只在设置页自证）

- 至少两个独立参考场景真实消费：资源列表（列表状态/列/分页/滚动恢复、批量操作确认、
  删除确认、复制反馈、搜索时机与历史）与创建/编辑/详情（草稿自动保存/恢复、提交去向、
  离开确认、重置确认、首字段/首错误聚焦、通知反馈）。参考数据保持确定性验收用途；新增
  本地会话操作明确标注参考范围，不伪装后端保存或任务。

## 非目标

- 不开放 debounce/刷新间隔等实现毫秒参数；数值对齐方式保持产品统一不开放配置；不建立
  Schema 编辑器或通用动态表单引擎。
- 草稿自动保存不等于业务提交，不承诺服务端持久化。
