# 通知、命令与快捷键

## 客户目标

作为后台用户，我希望重要的系统反馈与后台任务结果有统一去处（应用内通知中心），不重要的
成功提示按我的偏好收纳或定时消失；希望桌面通知在我主动开启后才请求权限；希望常用命令能
用统一的命令菜单/快捷键/按钮调用，且快捷键在输入时不误触。

## 使用场景与可验收行为

### 通知中心与反馈

- 通知中心收纳**真实前端反馈**（操作成功/失败/警告、系统通知）与**真实本地任务结果**
  （后台任务完成/失败）；不预填虚构通知。
- 每条通知表达：受控类别、严重性、关联 ID、展示文本、（可选）跳转目标；通知可标记已读/
  未读；未读有提醒；是否显示通知角标可配。
- 高风险、错误、安全相关提示**不能被完全关闭**（产品强制规则优先于用户偏好）。
- 非关键成功提示时长：短/标准/长（内部集中 3/5/8 秒，不暴露毫秒）；是否把非关键通知收纳
  到通知中心可配；通知中心持久化内容不含函数（只存可序列化数据，跳转经 Route Target）。
- 提示音开关：开启后成功/失败/任务完成等按类别播放；**声音播放失败**（浏览器限制/无设备）
  明确呈现，不静默。
- 浏览器桌面通知：默认关闭；**仅由用户点击触发权限请求**；权限拒绝、浏览器不支持、离线
  均明确呈现；只承诺应用运行期间的通知（不建设后台 Push）。
- 刷新/重进后通知中心内容保持（本地持久化），离线时新通知先入应用内中心（如适用），
  权限拒绝时降级为应用内呈现并说明原因。

### 命令（Command）与入口统一

- 命令的按钮入口、命令菜单、快捷键与常用操作引用**同一执行函数与可用性判断**，不复制
  逻辑。
- 命令可注册：命令 ID、说明、作用域、可用性（含禁用原因）与执行函数；组件/页面卸载时
  注销，不泄漏。
- 命令菜单（Ctrl/Cmd+K 保留）可搜索命令并执行；命令菜单内容 = 已注册命令 + 页面导航。

### 快捷键

- 快捷键统一注册：启用快捷键开/关（默认开）；输入框与输入法组合期间**避让普通导航命令**
  （不打断输入）。
- 保存命令只在当前表单可提交时生效（不可提交时禁用/说明原因）。
- 内置组合：打开命令菜单 `Ctrl/Cmd+K`（保留）；其余用统一的 `Alt+Shift` 组合；关闭页面
  标签不占用浏览器"关闭标签页"快捷键。
- 快捷键列表可查看与搜索；显示快捷键提示可配；快捷键设置不做任意键位编辑器。

## 非目标

- 不建设后台 Push / Service Worker 推送；不承诺应用关闭后的通知。
- 不做任意键位编辑器；不为通知/命令建设第二套 Provider 或 Service Locator。
- 桌面通知默认关，任何情况下都不在用户主动操作前请求权限。
