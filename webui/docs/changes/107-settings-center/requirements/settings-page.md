# 八分类设置页与即时生效

## 客户目标

作为后台用户，我希望打开"设置"就能在**一个页面**里按八类找到并修改我的偏好；每一项修改
**立即生效**（当前会话立刻按新值呈现）并**自动保存到当前浏览器**，我随时能看清每项的当前
值、说明、是否可修改与修改是否立即生效；我还能搜索设置项、跳到指定设置，并在需要时只恢复
某一类或全部设置到默认值——而不误清我收藏、历史、通知、草稿或已保存的筛选方案。

## 使用场景

- 打开设置 → 左侧分类导航（外观/导航/数据展示/操作偏好/语言与地区/通知/可访问性/快捷键），
  右侧显示该分类设置项；可直接输入 `?category=…&setting=…` 直达某个分类/设置。
- 切换主题/强调色/密度/字号/内容宽度/动效/对比度 → 页面与 Shell 立即按新值呈现。
- 搜"动画" → 定位到"外观 → 减少动态效果"（中英文同义词匹配）；清空搜索恢复搜索前分类。
- 点"恢复外观默认"/"恢复全部默认" → 弹确认框列出影响范围 → 只恢复偏好。

## 分类与设置项（可验收清单）

### 外观

- 主题模式：跟随系统 / 浅色 / 深色（切换立即预览；跟随系统响应系统深浅色变化）。
- 强调色：紫 / 蓝 / 绿 / 橙 四套受控预设；显示当前选择；不暴露 HEX/CSS Token。
- 界面密度：紧凑 / 标准 / 宽松；界面字号：小 / 标准 / 大。
- 内容宽度：自适应 / 标准 / 宽屏（宽屏保持当前内容上限语义不变）。
- 侧边栏外观：展开 / 紧凑 / 记住上次使用状态。
- 动效偏好：跟随系统 / 标准 / 减少动效；高对比度：跟随系统 / 标准 / 高对比度。

### 导航

- 登录后的默认首页；是否记住上次访问页面（最近入口）；是否记住侧边栏折叠状态；是否记住
  侧边栏展开的菜单（跨导航；当前页面祖先保持可见；遵守既有展开数量约束）。
- 页面跳转后是否自动滚动到顶部；面包屑显示开/关；顶部页面标签开/关、恢复上次打开标签、
  关闭当前标签后的跳转策略（最近使用 / 右邻优先 / 左邻优先）；离开未保存内容提醒；
  新页面打开方式（当前页面 / 新标签页——仅作用于允许的入口）。

### 数据展示

- 默认每页数量 10/20/50/100；表格密度三档；表格边界/分隔 Variant（仅现设计允许的）；
  固定表头开/关；是否记住列宽/列显示隐藏/列顺序；是否记住排序/筛选/分页位置；空数据辅助
  说明开/关；长文本默认处理（截断 / 换行）。
- 全局默认值 + 具体列表可保存自己的覆盖值（稳定页面/列 ID）；列设置保留必要标识列，
  恢复时过滤已退役列；分页在筛选/删除/页大小变化后校正；不恢复危险的批量选择状态。

### 操作偏好

- 编辑成功后默认去向（留在当前页 / 返回列表 / 进入详情，缺少详情目标的页面说明不适用）；
  创建成功后去向（返回列表 / 继续创建 / 打开新建详情）；本地草稿自动保存开/关（只写页面
  显式允许的字段；不等于业务提交成功；提交失败不清草稿）；离开未保存表单提醒；重置前确认；
  删除/批量/危险操作确认（危险操作既有输入确认不被削弱）；自动聚焦首字段（默认关）/校验
  错误后定位首错误（默认开）；复制内容后反馈；自动刷新数据（关闭 / 仅页面重新进入时 /
  定期刷新——统一预设周期，后台/离线/提交中暂停，不覆盖未提交编辑）；返回列表恢复筛选与
  滚动；详情附加信息展开与默认详情模式（仅项目已有模式）。

### 语言与地区

- 界面语言 简体中文/English；时区 自动/指定 IANA 时区；日期格式 YYYY-MM-DD / MM/DD/YYYY /
  DD/MM/YYYY；时间 24/12 小时制；是否显示秒；相对时间"5 分钟前"风格或精确时间；数字格式
  跟随地区；一周起始日 周一/周日。日期/数字/相对时间统一 i18n；纯日期不因时区偏移。

### 通知

- 系统通知、成功/失败/警告提示、后台任务完成提醒的开/关（高风险/错误/安全提示不可完全
  关闭）；是否播放提示音；是否允许浏览器桌面通知（默认关、仅用户点击触发权限请求；
  拒绝/不支持/声音失败明确呈现）；非关键成功提示时长（短/标准/长，内部 3/5/8 秒）；是否把
  非关键通知收纳到通知中心；未读提醒；是否显示通知角标。

### 可访问性

- 统一引用外观的动效/对比度/字号；增强焦点轮廓开/关；增强交互区域尺寸开/关；键盘操作
  提示；显示快捷键提示；跟随操作系统辅助功能设置。产品焦点/键盘底线不可关闭；大文字与
  增强点击区优先于紧凑密度；系统强制颜色模式保留浏览器控制权。

### 快捷键

- 启用快捷键开/关；查看与搜索快捷键列表；内置命令：打开命令菜单（Ctrl/Cmd+K 保留）、
  搜索、新建、保存、返回、页面切换、关闭当前标签（其余用统一 Alt+Shift 组合；关闭页面标签
  不占用浏览器关闭标签快捷键）；不提供任意键位编辑器。

## 统一规则（可验收）

- 每个设置项至少表达：当前值、名称、简短说明、是否可修改、是否由系统控制/跟随系统、
  修改后是否立即生效。避免大量 Badge 噪音（推荐/默认/跟随系统按需少量呈现）。
- 所有设置**即时生效并自动持久化**；持久化失败时保留当前会话效果并显示"未保存到此浏览器"
  原因与恢复动作，允许重试；损坏记录/未知版本/存储拒绝/容量不足显示原因与恢复动作，
  不静默覆盖、不宣称保存成功。
- 偏好通过浏览器 storage 事件同步（多窗口按最后成功写入的完整快照收敛）；当前窗口页签
  活动状态独立；草稿冲突不得静默覆盖。
- 外观与可访问性中的同义设置（动效/对比度/字号）共享同一存储字段；导航与表单的重复入口
  （离开提醒/删除确认）共享同一状态。
- 设置搜索匹配名称/说明/分类/中英文同义词；结果可定位并聚焦设置；清空恢复搜索前分类；
  搜索框自身不受业务搜索时机偏好影响。
- 关闭记忆类能力只停止后续记录与恢复，不删除已有内容；搜索历史提供单独明确清空操作。

## 非目标

- 不提供自定义圆角/阴影/间距/任意 CSS/任意 px/Design Token 编辑器；不做任意键位编辑器；
  不做可拖拽首页设计器；不做毫秒/秒级实现参数（debounce、刷新间隔）的用户输入。
- 设置不接账号/后端/跨设备同步；删除旧 preferences 页后不保留路由别名或旧入口。
