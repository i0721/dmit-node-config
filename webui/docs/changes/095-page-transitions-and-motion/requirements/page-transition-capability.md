# 页面转场能力需求

## 1. 客户目标

在工作台产品中，页面切换必须有可感知的转场与动效，让用户凭视觉直觉理解“我到了哪里、走了多深、能不能回去”，同时不损害弱动效用户、可访问性与页面性能。

## 2. 使用场景

- 从侧边栏进入任意工作页面，或从命令菜单、页内链接跳转时，观察到内容按“进入更深层级”的方向滑动过渡。
- 从浏览器后退/前进按钮返回时，页面以柔和方式切换（不假装有方向），不产生眩晕感。
- 切换过程中顶栏、侧边栏保持静止，用户始终有稳定的空间参照，只有内容区域在运动。
- 系统开启“减弱动态效果”时，页面切换接近瞬时完成，不出现位移运动。
- 不支持新转场能力的浏览器中，页面切换功能完全正常，只是没有动画。

## 3. 约束

- 动效时长、缓动与颜色全部来自产品既有语义规范，不为转场引入新颜色或装饰色。
- 转场不遮挡、不延迟真实交互；动画进行中页面仍可接受点击。
- 转场不提升首屏体积预算（不新增第三方动画依赖），CSS 增量必须保持在质量门禁预算内。
- 键盘、焦点、朗读与现有浮层（对话框、抽屉、菜单等）行为不因转场改变。

## 4. 非目标

- 不为单个页面元素新增装饰性动画；不改造对话框、抽屉、菜单等浮层的打开/关闭动效。
- 不做旧版系统动效迁移；不动 39 个 UI Element 的视觉与交互契约。

## 5. 可验收行为

| 编号    | 行为                                     | 验收                                                                                                                                                   |
| ------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| PTC-001 | 侧栏/命令菜单/页内链接导航有方向滑动转场 | 自动化在无 Suspense 页面断言捕获方向滑动动画（时长 ≥100ms）；带 Suspense 页面允许拆帧导致的部分/无动画（官方行为）；人工观感为“旧内容左移、新内容右入” |
| PTC-002 | 浏览器后退/前进切换不伪造方向            | 不出现方向性滑动；页面状态与 URL 正确（浏览器后退不携带转场类型，按官方行为瞬时切换或柔和过渡）                                                        |
| PTC-003 | 转场期间顶栏与侧栏保持静止               | 自动化/人工观测锚定元素无位移                                                                                                                          |
| PTC-004 | 减弱动态效果开启时无位移                 | 自动化断言动画时长 <50ms 或未观察到动画；人工确认无滑动                                                                                                |
| PTC-005 | 转场结束后 DOM 样式还原                  | 自动化断言页面元素不再残留转场样式                                                                                                                     |
| PTC-006 | 转场不破坏现有导航、键盘、焦点与浮层     | 既有 navigation/overlays/visual e2e 全部通过                                                                                                           |
| PTC-007 | 体积与构建预算不回归                     | `pnpm check` 全绿（含 performance:check CSS gzip 预算）                                                                                                |
| PTC-008 | 转场动效来自既有语义规范                 | 新增 CSS 只引用 design-system 的时长/缓动/颜色 Token，无硬编码值                                                                                       |
